# Dot 正式抖音发布入口

固定机器入口：<https://raw.githubusercontent.com/yuguangzsl/book-video-agent/main/daily/current.json>

网页入口：<https://github.com/yuguangzsl/book-video-agent/blob/main/daily/current.json>

本入口用于真实抖音发布，由本地项目校验内容后更新，Dot 在云电脑使用官方网页点击执行。此约定仅适用于本任务的抖音操作，依用户明确指令不要求 Dot 运行本地 `publish:*` 脚本。不涉及小红书自动发布。

## 当前状态

入口已建立，但尚未启用每日自动发布。首个候选《夜的命名术》存在 Dot 声称已发布、尚无官方证据的情况，必须先核实。正式视频地址尚未配置。账号及每日执行时间由 Dot 管理，不作为本地清单的必填或阻断条件。因此 `status=blocked`、`submitAuthorized=false`。这不是测试授权，也不是可执行的正式发布任务。旧 `dot-form-test-*` Release 保持测试性质，不能用作选片队列。

## 给 Dot 的持久任务指令

每次执行时读取上述固定机器入口；不要读取缓存、按 Release 时间排序或自行寻找替代视频。

1. 只有入口和内嵌 task 同时满足 `status=ready`、`mode=publish`、`testOnly=false`、`submitAuthorized=true` 才能继续。否则报告 `blockedReasons` 并停止。没有任务、读取失败或格式错误均停止，不沿用昨日任务。
2. `taskFile` 相对 GitHub 仓库根目录解析，不是相对 `daily/`。下载该不可变任务文件，验证原始 UTF-8 文件字节 SHA-256 等于 `taskSha256`，解析内容须与入口内嵌 task 完全一致。
3. 账号及执行时间由 Dot 自行管理，清单中为空不构成缺配置。仅在 `schedule` 明确提供日期或时间边界时核对：未到 notBefore 不提前提交，超过 expiresAt 不补发。当前清单每次只指定一个任务，每个账号每个北京时间自然日最多发布一条，不自行补发历史缺口。
4. 使用稳定的 `taskId` 和 `releaseId + renderSha256` 查持久执行记录，先原子领取任务，避免并发运行。如果无法持久记录、无法排除另一次执行或同日已发布，则停止。`account.id` 非空时必须匹配；为空时由 Dot 确定目标账号，并在本次上传、提交、查重和验证期间保持同一账号。不得因本地清单未指定账号而要求用户补填。登录失效或验证码需要用户处理。
5. 上传前检查官方作品列表和执行记录。发现同标题作品或不明确的提交，先保存证据并交由项目核对，禁止重复上传。单凭聊天声称“已发布”不能记为成功，也不能反向断定未发布。
6. 从 task.media.url 下载视频，核对大小及 SHA-256。只使用 task.copy 的标题、简介和话题；每个话题必须关联名称匹配的官方建议项。按 task.settings 核对所有选项，封面使用视频第 0 帧，须有可见场景、书名和作者。信息缺失、设置不符或话题不匹配时停止。
7. 最终提交前重新读取固定入口，确认 taskId、taskSha256 和授权状态未变，并再次核对账号、时间窗口、标题、简介、话题、设置和视频。完成校验后可执行一次最终发布，不需要同范围的再次人工确认。
8. 提交后进入官方作品列表，确认准确标题及对应最近作品在“已发布”或“审核中”状态，记录作品 ID/链接与时间，保存匹配作品可见的当前视口截图（不截整页）。只有这些证据齐全才记为已验证完成。
9. 点击发布后超时、断网或结果不明，记为 `unverified`，停止发布动作并先检查官方列表。没有权威缺席证据和新的重试授权，不重新上传、不重复点击。执行异常、无任务或被阻断都要反馈实际结果。
10. 向用户交付 taskId、releaseId、视频哈希、账号、标题、时间、作品 ID/链接、平台状态与截图。证据和账号执行记录保存在用户私有位置，不上传公开仓库。本地项目只有验证证据后才同步发布队列；本入口不自动完成该同步。

## 本地维护

本地生成工具：`node scripts/export-dot-publication.mjs --position <n>`。它验证当前队列、生产账本、READY 发布包和媒体哈希，只导出允许公开的字段。

准备正式任务时提供 `--media-url <HTTPS>`。账号和时间交由 Dot 管理，不提供也可生成 ready 任务。`--account-id <公开抖音号> --publish-date YYYY-MM-DD --publish-time HH:mm` 仅作为可选限制；传入时仍校验格式与有效期。缺少正式媒体地址会导出 blocked；`--hold-reason <原因>` 用于保留待核实阻断。账号参数是公开抖音号，不是密码或 Token。

正式媒体先上传并核对 GitHub 资产哈希，再上传新任务快照，最后更新 `daily/current.json`（建议同一 Git commit 原子更新）。不得把测试包改名后直接视为正式授权。每个任务快照路径含内容哈希，发布后不覆盖修改；固定入口负责指向当前版本。

生成默认输出到忽略目录 `.agents/dot-publication-export`。本次未建立自动上传、定时器、跨设备任务锁或结果回写服务；上述生成、远程更新、Dot 记录和本地证据同步必须由明确配置的执行流程完成。仅创建入口不意味着每日任务已启用。
